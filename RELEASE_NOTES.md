# RAGAM v2.1.1 Release Notes

### What's New
- **Smart Radio Engine**: Seamless algorithmic radio recommendations directly powered by YouTube Music InnerTube:
  - 📻 **Smart Radio Button**: Easily start a dynamic, similar-track radio mix from the PlayerBar, Now Playing view, or any song in your queue.
  - ♾️ **Endless Autoplay Queue**: Automatically discovers and appends matching songs as you near the end of your queue so the music never stops.
  - 🔀 **Seamless Queue Transition**: Keeps the active song playing uninterrupted while seamlessly generating the upcoming radio mix.
- **Windows Taskbar Thumbnail Media Controls**: Interactive media control buttons when hovering over the RAGAM taskbar icon:
  - ⏮ **Previous Track**
  - ⏯ **Play / Pause** (dynamic icon & tooltip)
  - ⏭ **Next Track**
- **Taskbar Playback Progress**: Real-time progress bar across the taskbar icon matching track playback.
- **Dynamic Track Title**: Active song title and artist displayed in the window title and taskbar tooltip.
- **Resilient WebView2 Startup**: Added automatic profile fallback handling to ensure smooth app startup across Windows sessions.
- **CI/CD Automated Releases**: Complete GitHub Actions workflow with automated package and delta building.
